## Sistema Bancário Simples em Java ##

Este é um projeto simples em Java desenvolvido como parte de um exercício extra praticado nos cursos da Alura. O objetivo principal é exercitar conceitos básicos que eu já conhecia de lógica de programação, como estruturas condicionais (`if/else`), laços de repetição (`while`) e entrada de dados via console.

## Funcionalidades ##

O sistema simula um menu de conta bancária via terminal com as seguintes opções:
1 - Consultar saldo: Exibe o saldo atual do usuário.
2 - Receber valor: Adiciona um valor inserido ao saldo total.
3 - Transferir valor: Realiza a transferência (Pix) validando se há saldo suficiente.
4 - Sair: Finaliza o programa.

## Tecnologias Utilizadas
Java (JDK 27)
Scanner (`java.util.Scanner`) para leitura de dados no terminal

## Conceitos Praticados
Laços de repetição (`while`)
Estruturas condicionais (`if`, `else if`, `else`)
Manipulação de variáveis e operadores aritméticos
Entrada e saída de dados via Console

## Como executar o projeto
Clone o repositório:
```bash
   git clone https://github.com/Hudglan/TesteFinal.git
   ```
Acesse a pasta do projeto:
```bash
   cd TesteFinal
   ```
Compile e execute o arquivo Java:
```bash
   javac Main.java
   java Main
   ```
